1. DESCRICAO FINAL DO SISTEMA
=========================================================
O sistema armazena as informações sobre a ocorrência de eventos, suas atividades e as sessões destas, que podem ocorrer em dias, horários e locais distintos, relacionando seus participantes e organizadores, podendo estes serem tanto pessoas como organizações. O sistema gerencia o limite de vagas e a alocação das sessões das atividades de acord com as necessidades da mesma.

=========================================================
2. DECISOES DE PROJETO
=========================================================
Q1: A tabela PROMOVE relaciona uma tupla da tabela PROMOTORES com uma tupla da tabela EVENTOS, relacionando assim um evento com seus N promotores, podendo ser tanto organizações quanto pessoas. Para tal, a tabela ORGANIZACOES e a tabela PESSOAS possuem a coluna "PromotorID", chave estrangeira que referencia a tupla correspondente na tabela PROMOTORES.

Q2: Fora criado o tipo ENUM 'participante_funcao' que representa as possíveis funções de um participante do evento, podendo ser 'Organizador', 'Apresentador' ou 'Participante'. Cada participante do evento pode ter diferentes funções por sessão, logo essa informação é armazenada em INSCRICOES, que relaciona cada participante com uma sessão.

Q3: A tabela SESSOES possui a coluna "AtividadeID", chave estrangeira que atrela N sessões à uma atividade, dessa forma, esse relacionamento N-1 (de SESSOES para ATIVIDADES) é satisfeito e uma atividade pode possuir várias sessões.

Q4: Na tabela EVENTOS, diferentes edições de um mesmo evento são tratados como evnetos distintos, pois atividades, informações e locais podem variar entre edições e simplificaria o tratamento dos dados.

Q5: A tabela SESSOES possui a coluna "Vagas", que pode ou não ser informada. Dessa forma, caso não seja informada, o número de vagas é posto como a capacidade máxima do espaço em que a sessão ocorrerá. Portanto, controla-se o número de inscrits observando o número de tuplas em INSCRICOES do tipo 'Participante' que existem no banco, e se este número é menor ou igual ao valor de "Vagas" na sessão correspondete. Ainda, se a atividade for 'on-line' ou se o espaço for um 'espaço aberto' (ou seja, capacidade e NULL), consideram-se vagas ilimitadas (isto é, se "Vagas" não for especificado na inserção da sessão no banco de dados).

Q6: Apenas a nova sessão é armazenada no banco, ignorando o histórico de sessões.

CREATE TYPE ferramentas AS ENUM(
    'Projetor',
    'Suporte à Transmissão',
    'Equipamento de Som',
    'Ar Condicionado'
);

CREATE TYPE ativ_modalidade AS ENUM(
    'On-line',
    'Presencial'
);

CREATE TYPE pessoa_sexo AS ENUM(
    'Masculino',
    'Feminino'
);

CREATE TYPE participante_funcao AS ENUM(
    'Organização',
    'Participante',
    'Apresentador'
);

CREATE TABLE EVENTOS(
    EventoID INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
    NomeEvento VARCHAR(100) NOT NULL,
    DataInicio DATE NOT NULL,
    DataFim DATE NOT NULL,

    CONSTRAINT evnt_data CHECK(DataFim >= DataInicio)
);

CREATE TABLE ESPACOS(
    EspacoID INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
    NomeEspaco VARCHAR(50) NOT NULL,
    Capacidade INTEGER,
    Endereco TEXT NOT NULL
);

    CREATE TABLE ESPACO_FERRAMENTA(
        EspacoID INTEGER,
        Ferramenta ferramentas,

        CONSTRAINT esp_ferr_fk PRIMARY KEY (EspacoID, Ferramenta),

        CONSTRAINT esp_ferr_esp_fk FOREIGN KEY (EspacoID) REFERENCES ESPACOS(EspacoID)
            ON DELETE CASCADE ON UPDATE CASCADE
    );

    CREATE TABLE ATIVIDADES(
        AtividadeID INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
        NomeAtividade VARCHAR(100) NOT NULL,
        Descricao TEXT,
        EventoID INTEGER,
        Modalidade ativ_modalidade NOT NULL,

        CONSTRAINT atv_evnt_fk FOREIGN KEY (EventoID) REFERENCES EVENTOS(EventoID)
            ON DELETE CASCADE ON UPDATE CASCADE
    );

        CREATE TABLE ATIVIDADE_FERRAMENTA(
            AtividadeID INTEGER,
            FerramentaNecessaria ferramentas,

            CONSTRAINT atv_ferr_pk PRIMARY KEY (AtividadeID, FerramentaNecessaria),

            CONSTRAINT atv_ferr_atv_fk FOREIGN KEY (AtividadeID) REFERENCES ATIVIDADES(AtividadeID)
                ON DELETE CASCADE ON UPDATE CASCADE
        );

        CREATE TABLE SESSOES(
            SessaoID INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
            EspacoID INTEGER,
            AtividadeID INTEGER NOT NULL,
            DataOcorre DATE NOT NULL,
            HorarioInicio TIME NOT NULL,
            HorarioFim TIME NOT NULL,
            Vagas INTEGER,

            CONSTRAINT sess_atv_fk FOREIGN KEY (AtividadeID) REFERENCES ATIVIDADES(AtividadeID)
                ON DELETE CASCADE ON UPDATE CASCADE,

            CONSTRAINT sess_esp_fk FOREIGN KEY (EspacoID) REFERENCES ESPACOS(EspacoID)
                ON DELETE RESTRICT ON UPDATE CASCADE,

            CONSTRAINT sess_horario CHECK(HorarioFim > HorarioInicio)
        );

CREATE TABLE PROMOTORES(
    PromotorID INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY
);
    CREATE TABLE PROMOVE(
        PromotorID INTEGER,
        EventoID INTEGER,

        CONSTRAINT promove_pk PRIMARY KEY (PromotorID, EventoID),
    
        CONSTRAINT promove_prom_fk FOREIGN KEY (PromotorID) REFERENCES PROMOTORES(PromotorID)
            ON DELETE RESTRICT ON UPDATE CASCADE,

        CONSTRAINT promove_evnt_fk FOREIGN KEY (EventoID) REFERENCES EVENTOS(EventoID)
            ON DELETE CASCADE ON UPDATE CASCADE
    );

    CREATE TABLE PESSOAS(
        CPF VARCHAR(11) PRIMARY KEY,

        Sexo pessoa_sexo,

        CONSTRAINT pess_prom_fk FOREIGN KEY (PromotorID) REFERENCES PROMOTORES(PromotorID)
            ON DELETE SET NULL ON UPDATE CASCADE
    );

        CREATE TABLE PESSOA_TELEFONE(
            CPF VARCHAR(11),
            Telefone VARCHAR(11),

            CONSTRAINT pessoa_tel_pk PRIMARY KEY (CPF, Telefone),

            CONSTRAINT pessoa_tel_cpf_fk FOREIGN KEY (CPF) REFERENCES PESSOAS(CPF)
                ON DELETE CASCADE ON UPDATE CASCADE
        );

        CREATE TABLE PARTICIPANTES(
            CPF VARCHAR(11),
            EventoID INTEGER,

            CONSTRAINT part_cpf_evnt_pk PRIMARY KEY (CPF, EventoID),

            CONSTRAINT part_cpf_fk FOREIGN KEY (CPF) REFERENCES PESSOAS(CPF)
                ON DELETE CASCADE ON UPDATE CASCADE,
            
            CONSTRAINT part_evnt_fk FOREIGN KEY (EventoID) REFERENCES EVENTOS(EventoID)
                ON DELETE CASCADE ON UPDATE CASCADE
        );

            CREATE TABLE INSCRICOES(
                CPF VARCHAR(11),
                EventoID INTEGER NOT NULL,

    CREATE OR REPLACE FUNCTION set_limite_vagas()
        RETURNS TRIGGER AS $$
        DECLARE limite_vagas INTEGER;
        BEGIN

            IF NEW.Vagas IS NULL THEN
                SELECT Capacidade INTO limite_vagas FROM ESPACOS WHERE EspacoID = NEW.EspacoID;
                NEW.Vagas := limite_vagas;
            END IF;

            RETURN NEW;
        END;
        $$  LANGUAGE plpgsql;

    CREATE OR REPLACE FUNCTION verifica_participante_evento()
        RETURNS TRIGGER AS $$
        DECLARE evento_id INTEGER;
        BEGIN

            SELECT A.EventoID INTO evento_id FROM SESSOES S
                JOIN ATIVIDADES A ON S.AtividadeID = A.AtividadeID
                WHERE S.SessaoID = NEW.SessaoID;

            IF(NEW.EventoID != evento_id) THEN
                RAISE EXCEPTION 'A pessoa com CPF % não é participante do evento da sessão %', NEW.CPF, NEW.SessaoID;
            END IF;

            RETURN NEW;
        END;
        $$ LANGUAGE plpgsql;

    CREATE OR REPLACE FUNCTION verifica_limite_vagas()
        RETURNS TRIGGER AS $$
        DECLARE 
            vagas_ocupadas INTEGER;
            limite_vagas INTEGER;
        BEGIN

            SELECT COUNT(*) INTO vagas_ocupadas FROM INSCRICOES WHERE SessaoID = NEW.SessaoID AND Funcao = 'Participante';

            SELECT Vagas INTO limite_vagas FROM SESSOES WHERE SessaoID = NEW.SessaoID;
            
            IF vagas_ocupadas >= limite_vagas THEN
                RAISE EXCEPTION 'Não é possível realizar a inscrição. Limite de vagas atingido para a sessão %', NEW.SessaoID;
            END IF;

            RETURN NEW;
        END;
        $$ LANGUAGE plpgsql;

    CREATE OR REPLACE FUNCTION verifica_ferramentas()
        RETURNS TRIGGER AS $$
        DECLARE ferramenta_necessaria ferramentas;
        BEGIN

            IF NEW.EspacoID IS NULL THEN
                RETURN NEW;
            END IF;

            FOR ferramenta_necessaria IN
                SELECT FerramentaNecessaria FROM ATIVIDADE_FERRAMENTA WHERE AtividadeID = NEW.AtividadeID
            LOOP
                IF NOT EXISTS(
                    SELECT 1 FROM ESPACO_FERRAMENTA WHERE EspacoID = NEW.EspacoID AND Ferramenta = ferramenta_necessaria
                ) THEN
                    RAISE EXCEPTION 'O espaço % não possui a ferramenta necessária % para a atividade %', NEW.EspacoID, ferramenta_necessaria, NEW.AtividadeID;
                END IF;
            END LOOP;

            RETURN NEW;
        END;
        $$ LANGUAGE plpgsql;
    
    CREATE OR REPLACE FUNCTION verifica_precisa_espaco()
        RETURNS TRIGGER AS $$
        DECLARE modalidade_atividade ativ_modalidade;
        BEGIN

            SELECT Modalidade INTO modalidade_atividade FROM ATIVIDADES WHERE AtividadeID = NEW.AtividadeID;

            IF modalidade_atividade = 'Presencial' AND NEW.EspacoID IS NULL THEN
                RAISE EXCEPTION 'A atividade presencial % precisa de um espaço definido', NEW.AtividadeID;
            END IF;

            RETURN NEW;
        END;
        $$ LANGUAGE plpgsql;    

    CREATE TRIGGER set_limite_vagas_trigger BEFORE INSERT OR UPDATE ON SESSOES
        FOR EACH ROW EXECUTE FUNCTION set_limite_vagas();
    
    CREATE TRIGGER verifica_participante_evento_trigger BEFORE INSERT OR UPDATE ON INSCRICOES
        FOR EACH ROW EXECUTE FUNCTION verifica_participante_evento();

    CREATE TRIGGER verifica_limite_vagas_trigger BEFORE INSERT ON INSCRICOES
        FOR EACH ROW EXECUTE FUNCTION verifica_limite_vagas();

    CREATE TRIGGER verifica_ferramentas_trigger BEFORE INSERT OR UPDATE ON SESSOES
        FOR EACH ROW EXECUTE FUNCTION verifica_ferramentas();

    CREATE TRIGGER verifica_precisa_espaco_trigger BEFORE INSERT OR UPDATE ON SESSOES
        FOR EACH ROW EXECUTE FUNCTION verifica_precisa_espaco();

CONSULTA 1
OBJETIVO: Verificar a quantidade de inscritos em um evento específico, separando por função e contabilizando o total de inscritos.
SQL: SELECT E.NomeEvento, A.NomeAtividade, I.Funcao, COUNT(*) AS nesta_funcao, SUM(COUNT(*)) OVER(PARTITION BY A.AtividadeID) AS total_atividade FROM INSCRICOES I
    JOIN SESSOES S ON S.SessaoID = I.SessaoID
    JOIN ATIVIDADES A ON A.AtividadeID = S.AtividadeID
    JOIN EVENTOS E ON E.EventoID = A.EventoID
    WHERE A.EventoID = 1
    GROUP BY E.EventoID, E.NomeEvento, A.AtividadeID, A.NomeAtividade, I.Funcao
    ORDER BY A.AtividadeID ASC, I.Funcao DESC;

CONSULTA 2
OBJETIVO: Contabiliza quantas pessoas estão inscritas em cada evento, separando por sexo.
SQL: SELECT E.NomeEvento, P.Sexo, COUNT(*) AS quantidade_sexo, SUM(COUNT(*)) OVER(PARTITION BY E.EventoID) AS total_participantes FROM PARTICIPANTES PA
    JOIN PESSOAS P ON P.CPF = PA.CPF
    JOIN EVENTOS E ON E.EventoID = PA.EventoID
    GROUP BY E.EventoID, E.NomeEvento, P.Sexo
    ORDER BY E.NomeEvento ASC, P.Sexo DESC;

CONSULTA 3
OBJETIVO: Encontra, para todas as atividades, espaços que podem sedia-lás de acordo com as ferramentas necessárias.
SQL: SELECT A.NomeAtividade, E.NomeEspaco, E.Capacidade, E.Endereco FROM ATIVIDADES A
    CROSS JOIN ESPACOS E
    WHERE NOT EXISTS(
        SELECT 1 FROM ATIVIDADE_FERRAMENTA AF
            WHERE AF.AtividadeID = A.AtividadeID AND NOT EXISTS(
                SELECT 1 FROM ESPACO_FERRAMENTA EF
                    WHERE EF.EspacoID = E.EspacoID AND EF.Ferramenta = AF.FerramentaNecessaria
            )
        )
    GROUP BY A.AtividadeID, E.EspacoID
    ORDER BY A.AtividadeID ASC, E.Capacidade DESC;

CONSULTA 4
OBJETIVO: Lista todas as atividades, as suas sessões e os espaços em que elas ocorrerão.
SQL: SELECT A.NomeAtividade, A.Modalidade, S.SessaoID, S.DataOcorre, S.HorarioInicio, S.HorarioFim, COALESCE(E.NomeEspaco, '-online-') AS NomeEspaco FROM ATIVIDADES A
    JOIN SESSOES S ON S.AtividadeID = A.AtividadeID
    LEFT JOIN ESPACOS E ON E.EspacoID = S.EspacoID
    GROUP BY A.AtividadeID, S.SessaoID, E.EspacoID
    ORDER BY A.AtividadeID, S.DataOcorre, S.HorarioInicio;

CONSULTA 5
OBJETIVO: Retorna todos os promotores de um evento específico, especificando entre pessoas e organizações, juntamente com seus documentos e nomes.
SQL: SELECT E.NomeEvento, PR.PromotorID,
    CASE
        WHEN P.CPF IS NOT NULL THEN 'Pessoa Física'
        WHEN O.CNPJ IS NOT NULL THEN 'Organização'
    END AS TipoPromotor,
    COALESCE(P.NomePessoa, O.RazaoSocial) AS NomePromotor,
    COALESCE(P.CPF, O.CNPJ) AS Documento
FROM EVENTOS E
    JOIN PROMOVE PM ON PM.EventoID = E.EventoID
    JOIN PROMOTORES PR ON PR.PromotorID = PM.PromotorID
    LEFT JOIN PESSOAS P ON P.PromotorID = PR.PromotorID
    LEFT JOIN ORGANIZACOES O ON O.PromotorID = PR.PromotorID
    WHERE E.EventoID = 2 AND (P.CPF IS NOT NULL OR O.CNPJ IS NOT NULL)
    ORDER BY NomePromotor ASC;
